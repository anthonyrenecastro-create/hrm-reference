# Provenance and ownership review

This record documents the pre-publication provenance review for the HRM reference implementation.
It does not replace a legal ownership review or the licensor's personal attestation.

## Repository origin

- The HRM theory and implementation requirements were supplied by Anthony Castro.
- The repository was created specifically for Anthony Castro from those materials.
- The implementation, tests, documentation, configurations, schemas, and retained synthetic
  results were generated for this repository rather than copied from another software project.
- No third-party source tree or vendored package is included in the tracked repository.
- Runtime and development dependencies are declared in `pyproject.toml`; they remain under their
  respective licenses and are not relicensed under the repository license.
- Reference artifacts contain synthetic outputs generated by the repository's own tasks.

## Automated review performed

Before public release, the tracked files are checked for:

- residual Apache license declarations outside the historical changelog statement;
- GPL, AGPL, LGPL, proprietary-license, or third-party copyright markers;
- untracked or vendored source trees;
- consistency among `LICENSE`, `NOTICE`, `README.md`, `pyproject.toml`, and `CITATION.cff`;
- package metadata containing the SPDX expression `PolyForm-Noncommercial-1.0.0`.

Review snapshot on 2026-07-13:

- 173 repository paths are expected after this licensing update, including 118 Python files across
  source, tests, examples, and benchmarks;
- no Git submodule entries or common vendored-source directories were found;
- no copyright, SPDX header, GPL, AGPL, LGPL, proprietary-license, or other embedded license marker
  was found in the implementation, tests, examples, or benchmark Python files; and
- the only remaining Apache reference is the changelog statement preserving the historical license
  boundary for version 0.1.0.

Automated text inspection cannot prove authorship or detect every possible similarity to external
code. Dependency license compliance must also be assessed separately before distributing bundled
dependencies.
