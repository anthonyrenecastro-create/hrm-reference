# Claims boundary

| Level | Repository evidence | Status |
|---|---|---|
| Specified | theory-to-contract documentation | achieved |
| Implemented | executable state, transition, mechanisms, tasks, controls | achieved |
| Activated | per-run mechanism gate report | measured per workload |
| Attributable | exact transition ledger and independent verifier | achieved for ledger-valid runs |
| Synthetically supported | matched task utility after all gates | not presumed; experiment-specific |
| Externally supported | independent real-world workload evidence | not established |
| Validated | replicated broad empirical evidence | not established |

This repository does not establish consciousness, general intelligence, biological equivalence, a
new physical law, or superiority over conventional computing. It is a conservative reference
implementation and an instrument for falsifiable synthetic experiments.

Current limitations include a fixed maximum carrier with identity transport, one coarse hierarchy
level, an explicit-Euler CPU backend, synthetic tasks, no learned parameter-fitting pipeline, and no
external replication. Edge flips are an optional declared event type but deliberately unsupported.
Topology and geometry heuristics are reference choices where the theory leaves functions
underspecified; they are configurable engineering choices, not derived theorems.
